# Member Profile

Every member has a public profile visible to other authenticated members.

## Public profile fields

These fields are visible to anyone on the platform:

| Field | Description |
|---|---|
| Full name | Member's display name |
| Avatar | Profile photo |
| Cover image | Banner image behind the avatar |
| Bio | Short description |
| Discipline | e.g. Frontend Engineering, Product Design |
| Experience level | Complete Beginner → Expert / Senior |
| Skills | List of skill tags |
| Location | City / country |
| GitHub handle | Links to GitHub profile |
| Twitter handle | Links to Twitter/X profile |
| LinkedIn URL | Links to LinkedIn profile |
| Website URL | Personal or portfolio site |
| Discord username | Community Discord handle |
| Community roles | Badges showing assigned roles |
| XP total | Coming Soon |
| Badges | Coming Soon |

## Private fields (never shown publicly)

These fields are stored but never displayed on the public profile:

- Date of birth
- Email address
- Community ID
- Referral source
- Primary goal
- Community goals

## Editing your profile

Members edit their own profile at Settings → Profile. Changes are saved immediately and reflected on the public profile.

## Profile URL

Public profiles are accessible at `/@username`.

Any authenticated member can view any other member's public profile.
